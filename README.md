# Study Abroad Buddy

A MERN stack web app that helps students prepare for studying abroad. Get personalised visa, health, culture, and housing guides for your destination, plus an AI chatbot that answers your questions using the right specialist agent.

---

## Features

- Personalised visa, health, culture, and housing guides based on your destination
- AI chatbot with 5 specialist agents (Visa, Health, Culture, Housing, General)
- RAG pipeline using ChromaDB for grounded, source-backed answers
- Pre-departure checklist generated by AI and personalised to your trip
- JWT-based authentication with a 3-step onboarding wizard

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React + Vite + Tailwind CSS + React Router v6 |
| Backend | Node.js + Express.js (port 5000) |
| Database | MongoDB Atlas + Mongoose |
| Vector DB | ChromaDB (local, port 8000) |
| AI | OpenAI API — gpt-4o, gpt-4o-mini, text-embedding-3-small |
| Auth | JWT + bcrypt |

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/study-abroad-buddy.git
cd study-abroad-buddy
```

### 2. Install server dependencies

```bash
cd server
npm install
```

### 3. Install client dependencies

```bash
cd ../client
npm install
```

### 4. Set up environment variables

**Server — create `server/.env`:**

```
MONGODB_URI=your_mongodb_atlas_connection_string
JWT_SECRET=any_long_random_string_you_choose
OPENAI_API_KEY=your_openai_api_key
CHROMA_URL=http://localhost:8000
PORT=5000
```

**Client — create `client/.env`:**

```
VITE_API_URL=http://localhost:5000
```

> **Never commit `.env` files.** They are excluded by `.gitignore`.

### 5. Install and start ChromaDB

ChromaDB requires Python. Install it with pip:

```bash
pip install chromadb
```

Then start the ChromaDB server (run this from the project root):

```bash
chroma run --path ./chroma-data
```

Leave this terminal window open — ChromaDB must be running for the AI agents to work.

### 6. Set up the ChromaDB collections and ingest data

Open a **new terminal**, go to the server folder, and run these two scripts in order:

```bash
cd server

# Creates the three ChromaDB collections
node scripts/createCollections.js

# Ingests all source documents into ChromaDB
node scripts/ingest.js
```

You only need to do this once. The data is saved in the `chroma-data/` folder.

## Running the App

You need **three terminals** running at the same time:

**Terminal 1 — ChromaDB**
```bash
chroma run --path ./chroma-data
```

**Terminal 2 — Backend server**
```bash
cd server
npm run dev
```

**Terminal 3 — Frontend**
```bash
cd client
npm run dev
```

Then open your browser and go to: **http://localhost:5173**

## First Time Use

1. Go to `http://localhost:5173` and click **Register**
2. Create an account with your name, email, and password
3. Complete the **3-step onboarding wizard**:
   - Step 1: Select your home country
   - Step 2: Select your destination country and city
   - Step 3: Enter your university name and travel dates
4. You'll be taken to your **Dashboard** where your personalised checklist will be generated
5. Explore the Visa, Health, Culture, and Housing guides from the dashboard
6. Use the **AI Chat** to ask any questions about your trip

## Available Scripts

From the `server/` folder:

| Script | What it does |
|---|---|
| `npm run dev` | Starts the backend with nodemon (auto-restarts on file changes) |
| `node scripts/createCollections.js` | Creates the three ChromaDB collections (run once) |
| `node scripts/ingest.js` | Ingests source documents into ChromaDB (run once) |
| `node scripts/testAgents.js` | Tests all 5 agents with a sample profile |
| `node scripts/testClassifier.js` | Runs 20 test queries through the intent classifier |

From the `client/` folder:

| Script | What it does |
|---|---|
| `npm run dev` | Starts the frontend dev server on port 5173 |
| `npm run build` | Builds the frontend for production |

## Troubleshooting

**"Cannot connect to ChromaDB"**
ChromaDB is not running. Start it with `chroma run --path ./chroma-data` and leave that terminal open.

**"Server error" on login or register**
Your `MONGODB_URI` in `server/.env` is likely wrong or your MongoDB Atlas cluster hasn't whitelisted your IP address. Go to MongoDB Atlas → Network Access → Add your current IP.

**Frontend shows blank page or network error**
Make sure the backend is running on port 5000 and your `client/.env` has `VITE_API_URL=http://localhost:5000`.

**OpenAI errors in the chat**
Check that `OPENAI_API_KEY` in `server/.env` is correct and your OpenAI account has available credits.
